    How far the item metaphor carries

    Holds exhibits 1–3

    A server hands over a kit

    The tool list is the inventory. The description is the tooltip. Tools are items you use; resources are books you read.

    Stretches exhibits 4–8

    Then the items get strange

    An item with small print only the model reads. One that changes in the hand. One that asks its holder a question, opens its own screen, or is the map.

    Stops and that is the lesson

    You are not the one holding them

    The model holds the kit. You watch over its shoulder, and the host decides which slots exist and when you are asked. No game has that.

    Three builds, each one more real

    Build 1 · this page

    Simulated bench

    Server handlers in the browser, scripted model. No install, runs on a phone, safe to hand to anyone. Good for the dinner-table explanation.

    Build 2 · recorded

    Replayed evidence

    The same eight servers as real stdio processes. Run them in real hosts, record the transcript, replay it here with host, version and date on every run.

    Build 3 · live

    Differential bench

    One specimen server, several hosts, one mutation per run. Which host shows the full description? Which re-asks after a tool changes? Agreement is also a result.
