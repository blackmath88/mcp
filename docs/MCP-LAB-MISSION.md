# MCP Lab: current learning mission

Accepted direction: an IDE-style workbench about MCP generally, for technically curious newcomers. Begin with recognizable real integration tasks, show the spectrum of possibilities, then explore boundaries and weird uses. Preserve the interactive center, explorer, inspector and activity region. Previous Teams/room/Personas and PDF/Excel examples are excluded from the learner curriculum.

First build: one fully playable notes model (find a packing list, attempt an edit, vary access, observe the result), plus seven clearly labelled source-backed previews. The model illustrates a real integration pattern; it is not live Notion, a running AI assistant, or captured MCP traffic. Illustrative operation names are not represented as official service tool schemas. Live integration is a distinct future execution mode.

Navigation: Basics / Possibilities / Edges, with Weird as a cross-cutting filter. The taxonomy is instructional, not an official protocol classification. Popularity labels need a population, measure and date; star counts are not users.

Human checkpoint: try the first experience and explain where the information came from, what changed the note and why a write can fail. Until that feedback exists, learning remains unverified. Additional runnable integrations follow this feedback rather than scaling an untested teaching pattern.
