# Knowledge and learning integration — protocol lab proposal
2026-11-27 | Design note

MCP Lab already supplies in-browser simulated tools, CLI and stdio protocol exercises, and Lab Factory tooling. Use it as a synthetic reference/test corpus, not as a gateway to private knowledge.

Proposed specimens: read-only source-scoped retrieval, historical evidence, bounded context, proposal-only submission, human acceptance outside model authority, revocation and persistent prompt-injection defenses. Compare discovery and execution rights; test denied source non-disclosure including derived summaries, tool descriptions and error responses. Record protocol frames with synthetic data only. No production endpoints, credentials or private corpus; no deployment or new runtime dependency implied.
