# Exhibit review: learning workbenches

Status: project-local working rubric, applied first to the MCP newcomer curriculum. This supplements the Lab Factory workflow; it does not turn an agent's assessment into human acceptance.

Before building an exhibit, record:

- Audience and prior knowledge; the one idea this interaction should help explain.
- A recognizable task backed by a real implementation and a dated primary source.
- The central object the visitor sees, the control they change, and the visible consequence.
- The normal path, one meaningful failure/boundary, and reset behavior.
- Actual execution mode: illustrative model, recorded real exchange, or live integration. For models, distinguish illustrative operation names from official wire/tool names.
- What's intentionally outside the exhibit. A service integration's capabilities are not automatically MCP guarantees.

Review four separate outcomes:

| Outcome | Evidence | Who can assess |
| --- | --- | --- |
| Source correctness | Dated primary sources, scoped claims, observed versus inferred | Researcher and independent reviewer |
| Functional behavior | Reproducible action/result checks, unchanged state on rejected actions | Deterministic checks plus reviewer |
| Usability | Visible task/action/result, keyboard navigation, viewport inspection, contextual explanation | Browser checks and human/agent review, with limits |
| Learning | Visitor explains the mechanism or predicts a changed condition | Human feedback; no inferred pass from clicks or tests |

Do not equate popularity with stars or vendor status. Label catalog entries that are only previews; don't make a nonfunctional tile look like a working integration. Keep reviewed source revisions distinct from later fixes. Record findings with artifact IDs; preserve failures and unknown usage/cost instead of inventing metrics.

Stop expanding an exhibit family until the first teaching interaction is inspectable by the user. Multiple agents can research independent directions, but one owner integrates the application and its navigation.
