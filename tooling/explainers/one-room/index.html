03 / WHAT MCP ACTUALLY DOES

A common way
to ask software.

MCP is a protocol: a shared way for a client to discover a tool, send structured arguments, and receive its result. The host controls which connections and actions are available.

The real work still happens inside the tool. Here, Personas validates the project and uses Chromium to render it on linuc.

Models helped investigate and review. A deterministic script performed this pilot’s tool calls.

05 / REALITY PUSHES BACK

Correct data.
Broken presentation.

The original detail view put a house and Teams side by side. After the move, its houses exceeded the slide’s layout budget. The renderer refused the result.

That failure stays in the record. We changed the preview to a compact Teams view in both comparison inputs. The overview still shows houses.

The failure is a finding: a valid operation does not guarantee a useful output.
